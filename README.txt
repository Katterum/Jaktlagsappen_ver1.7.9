Jaktlaget v1.8.0 uppgradering

1. Lägg v180.js, v180.css och install_v180.py i samma mapp som appens index.html.
2. Kör: python install_v180.py
3. Publicera hela appmappen på nytt.
4. Om telefonen visar gammal version, stäng appen helt och öppna den igen.

Tillägg:
- Kalender med månadsvy och markeringar på startsidan.
- Ny Tilldela pass-funktion med medlemmar, lösa namn, egna pass, slumpning, kopiering och nollställning.
- Grupperad Mer-sida utan ändrad knappdesign.
- Skjutna djur per skytt, viltslag och åldersklass.
- Komplett passprognos med vindriktning, vindstråk, ljus, sikt, nederbörd och djurslagschanser.

Befintliga appdata ligger kvar i localStorage och ändras inte av installationen.
